# Quickstart

1. Open repository root.
2. Confirm repository scope by running: git rev-parse --show-toplevel.
3. Run Speckit workflow in this repository only: /speckit.plan, /speckit.tasks, /speckit.analyze, /speckit.implement.
4. Read specs/1-general-requirements-business-user/spec.md and specs/1-general-requirements-business-user/plan.md.
5. Run generated tasks from specs/1-general-requirements-business-user/tasks.md.
